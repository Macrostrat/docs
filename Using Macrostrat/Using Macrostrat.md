Macrostrat's data are open to everyone, under a
[CC-BY 4.0 license](https://creativecommons.org/licenses/by/4.0/). There are three main
ways to use them:

- **In a browser.** Macrostrat's website includes an interactive geologic map, column
  and map browsers, and pages for every term in the lexicon. See [[Web interfaces]].
- **Through the API and map tiles.** Every dataset is available through a public web
  API, and the geologic map is served as vector and raster tiles for use in web maps
  and GIS. See [[Data services]], [[The Macrostrat Geologic API]] and
  [[Accessing column data]].
- **In GIS software.** Macrostrat's map layers can be streamed directly into QGIS. See
  [[Use in QGIS]].

On a phone, the [Rockd](https://rockd.org) app puts Macrostrat's geologic context in
your pocket, with tools for recording and sharing observations in the field.

Common questions are answered in [[Frequently asked questions]]. When you publish work
that uses Macrostrat, cite the platform and the original sources of the data you used;
the API returns those references with every record.
