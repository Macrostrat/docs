Everything Macrostrat runs on is open source, developed in public on GitHub in two
organizations: [UW-Macrostrat](https://github.com/UW-Macrostrat) (the core platform,
the website, the API and Rockd) and [Macrostrat](https://github.com/Macrostrat) (this
documentation and newer community-facing repositories).

## Contributing code

Open an issue first for anything beyond a small fix, so we can point you to the right
place; the platform spans several repositories that release independently. Each
repository's README says how to run it. Conventions for the web codebases are in the
[the website's code style guide](https://github.com/UW-Macrostrat/web/blob/main/CONTRIBUTING.md).

## Contributing documentation

This site's prose lives in the [documentation repository](https://github.com/Macrostrat/docs),
an Obsidian vault of Markdown. Clone it, edit, open a pull request; no build tools are
needed. See [[About this vault]].
