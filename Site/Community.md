Macrostrat is built by geologists, for geologists, and it gets better with every
contribution. There is a way in at every level of effort. Start wherever fits.

## Ways to contribute

1. **Collect and document your geologic world.** Every Rockd checkin, photo and
   strike-and-dip measurement adds an observation to the record. Everything we do as
   geologists helps. [Get Rockd](https://rockd.org).
2. **Tell us what is wrong.** A unit in the wrong place, a legend that does not match
   the map, a missing name: reporting it is a contribution. Use the feedback link on
   any page, or the channels below.
3. **Digitize existing geologic data.** Maps, stratigraphic columns, measured sections
   and drill logs that exist only on paper or in a drawer. The guides in the
   documentation explain the formats: [[Maps]], [[Accessing column data]].
4. **Build on Macrostrat.** The API, tiles and web components are open. When you have
   built something, add it to [apps built with Macrostrat](/community/apps).
5. **Connect a system.** If you run a data system that could exchange data or
   identifiers with Macrostrat, see [integrations](/community/integrations).
6. **Contribute code and documentation.** Everything is open source; see
   [open source](/community/open-source).
7. **Fund the work.** Grants, gifts and in-kind support are described on the
   [support page](/about/support).
